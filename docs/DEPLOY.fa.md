# نصب و مهاجرت

[English](DEPLOY.md) · [انتشار نسخه](MAINTAINER.fa.md)

## با ربات

در [ربات Omni](https://t.me/OmniAiGateBot) `/start` را بفرستید و پنل خودتان را بسازید یا انتخاب کنید. حساب‌ها و منابع باید متعلق به شما یا تحت اختیار مجازتان باشند. قبل از ارتقا، SQL و تنظیمات را پشتیبان بگیرید.

## نصب مستقل

1. Node.js 22+ نصب کنید، سپس `npm ci`، `npm run build` و `npm test` را اجرا کنید.
2. در Cloudflare یک D1 و namespaceهای `KV` و `RELEASES` بسازید. `wrangler.toml` را به `wrangler.local.toml` کپی و placeholderها را با مقادیر خودتان عوض کنید.
3. **نصب مقداردهی‌نشده را موقتاً خصوصی کنید** و پیش از دسترسی عمومی، حساب مدیر را بسازید. اولین بازدیدکننده نباید بتواند setup را تصاحب کند.
4. برای ربات شخصی، `BOT_TOKEN` و `BOT_WEBHOOK_SECRET` تصادفی را به‌صورت secret تنظیم کنید. وب‌هوک باید هم URL خصوصی و هم `secret_token` همسان داشته باشد.
5. پس از بازبینی، اجرا کنید:

```bash
OMNI_ALLOW_DEPLOY=1 OMNI_WRANGLER_CONFIG=wrangler.local.toml npm run deploy
```

همان `panel/build/worker.js` را در namespace انتشار با کلید `releases/current` بگذارید. انتشار KV آنی نیست؛ پیش از ساخت/آپدیت نود، همگامی را بررسی کنید. این فرمان مستقل به‌جای شما SQL پشتیبان نمی‌گیرد.

## نصب موجود

D1، bindingها، سازگاری runtime، mappingهای Durable Object، زمان‌بندی و فایل فعلی Worker/RELEASES را نگه دارید. migration نمونه فقط برای نصب تازه است. وب‌هوک قدیمی را پیش از انتقال با `secret_token` دوباره ثبت کنید؛ حفظ URL به‌تنهایی کافی نیست. توکن یا secret را داخل دستور عمومی و issue نگذارید.

ابتدا یک نود متعلق به خودتان را منتقل کنید. نسخه، ورود، کاربران، اشتراک، تلگرام و اتصال واقعی را بررسی کنید؛ بعد سراغ بقیه بروید. برای بازگشت کد، Worker و RELEASES همسان قبلی را برگردانید؛ SQL قدیمی را صرفاً برای undo کد روی داده‌های جدید ننویسید.

## Railway

کل ریپو را فورک و Dockerfile ریشه را برای ساخت رله انتخاب کنید. پنل اصلی روی Cloudflare می‌ماند. رله تا تعیین مقصد، تونل باز نمی‌کند؛ از بخش Railway پنل، سرویس متعلق به همان حساب را متصل کنید. فورک، محدودیت سهمیه یا پرداخت Railway را برنمی‌دارد.

**پشتیبان SQL و کانفیگ‌ها محرمانه‌اند.** اطلاعات ورود افشاشده را تعویض کنید؛ پاک‌کردن فایل، نسخه‌های قدیمی آن را بی‌اثر نمی‌کند.
