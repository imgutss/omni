# وضعیت معتبر v10.1 — VPS + CDN ایرانی — ۲۰۲۶-۱۰-۱۰

## نتیجهٔ روشن
اصلاح نرم‌افزار روی هر دو پنل منتشر شده است. **هنوز هیچ VPS واقعی به این پنل‌ها وصل نیست و اتصال در نت ملی تأیید نشده است.** تست قبلی که با گزارش مصنوعی نود انجام شد فقط API/ساخت لینک را پوشش می‌داد؛ ادعای قبلی «کل زنجیره واقعی کار می‌کند» درست نبود.

## روش موردنظر و تفاوتش با v10
مسیر پیشنهادی مشابه آموزش بررسی‌شدهٔ اسپایدر: گوشی → لبهٔ CDN ایرانی → مبدا دارای اینترنت جهانی (معمولاً VPS خارجی) → اینترنت.
سرور روی اسنپ یا سایت دیگر نصب نمی‌شود. نام/IP سایت دیگر فقط در صورت هم‌CDN بودن و سازگاری همان لبه می‌تواند Address آزمایشی باشد. عضویت فعلی اسنپ یا هیچ دامنهٔ دیگری در CDN مشخص، در این مرحله تأیید نشده است.
در خروجی، Host و SNI واقعی دامنهٔ خود کاربر می‌مانند. قابلیت `snispoofing`، با `fakeSni` و `spoofIp`، پارامتر جداگانهٔ کلاینت سازگار است؛ جایگزین کردن SNI معمولی با snapp.ir همان روش نیست. v2rayNG معمولی را پشتیبان این افزونه فرض نمی‌کنیم.
مرجع کد بررسی‌شده: https://github.com/amirh00sain/SpiderPanel/blob/main/main.py — توابع `_spoof_payload`، `_default_tls_ws_feature_params`، `_default_ws_address` و `generate_user_config`.

## آنچه پیاده و منتشر شد
- بخش پولی جدا: «💎 VPS + CDN ایرانی» با فرم دامنهٔ خودت، Address، مسیر WS، کاربر و فیلدهای اختیاری Fake SNI / Spoof IP.
- مبدا WS+TLS با اعتبارسنجی گواهی؛ خروجی عادی و خروجی جداگانهٔ کلاینت سازگار با Spoof. REALITY مستقیم از روش CDN جدا و بدون پیش‌فرض گمراه‌کنندهٔ snapp.ir است.
- اسکریپت نصب Debian/Ubuntu + systemd؛ ایجنت پایدار پس از راه‌اندازی مجدد؛ دانلود Xray با بررسی checksum؛ قطع ارتباط مدیریت به‌تنهایی Xray را متوقف نمی‌کند.
- خطای certbot یا Xray دیگر موفقیت اعلام نمی‌شود. کانفیگ قبل از اعمال بررسی می‌شود، شکست راه‌اندازی به کانفیگ قبلی برمی‌گردد و پروفایل بازنویسی‌شده تبلیغ نمی‌شود.
- اصلاح Cloudflare 1010 برای User-Agent پیش‌فرض Python: درخواست‌های join/poll/report با شناسهٔ `Omni-VPS-Agent/10.1` ارسال می‌شوند.
- مهاجرت مستقل جداول VPS برای پنل‌های نصب‌شدهٔ قدیمی؛ مسیر bootstrap قدیمی به‌تنهایی کافی نبود.
- ورود به اشتراک فقط پس از تأیید صریح آزمایش خط توسط کاربر؛ تأیید به URI دقیق و UUID نصب‌شده وابسته است. پارامتر Spoof فقط در خروجی `?type=v2box` نگه داشته می‌شود، نه اشتراک عمومی v2rayNG.

## آنچه هنوز انجام نشده / نیاز واقعی دارد
**حساب CDN، انتقال NS، تنظیم DNS و مبدا CDN خودکار ساخته نشده‌اند.** دسترسی این سرویس هنوز به برنامه داده نشده است. برای درخواست اولیهٔ «همهٔ مراحل خودکار با دامنه/VPS» این بخش هنوز باقی است؛ نوشته‌شدن فرم را معادل اتصال واقعی CDN نمی‌دانیم.
دامنهٔ متعلق به کاربر باید روی CDN آماده باشد؛ WebSocket روشن، کش/چالش مرورگر روی مسیر WS خاموش، HTTP پورت ۸۰ برای ACME به مبدا برسد و HTTPS به ۴۴۳ مبدا با اعتبارسنجی گواهی وصل شود. بعد نصب مبدا انجام و خروجی روی خط واقعی آزمایش می‌شود.
باقی‌ماندن ارتباط CDN تا مبدا شرط است. قطع کامل آن مسیر با تغییر SNI رفع نمی‌شود. نصب اولیه به مخزن بسته‌ها، GitHub و پنل نیاز دارد.

## شواهد و حدودشان
- تست مرورگر فرم‌ها/خروجی/تأیید دستی: mock، بدون خطای JS و بدون سرریز موبایل؛ نه اثبات اتصال ایران.
- آزمون API و D1 روی Miniflare محلی: چرخهٔ کامل، مهاجرت از نسخهٔ قدیمی، رد ورودی نامعتبر، UUID درست، تأیید/لغو و جلوگیری از نشر کانفیگ آزمایش‌نشده.
- ۸ تست واحد ایجنت؛ smoke قدیمی ۱۵/۱۵؛ تست‌های اشتراکی URI و سینتکس اسکریپت سرو‌شده.
- Xray واقعی فقط روی loopback: WS+TLS با بررسی گواهی، احراز VLESS و رفت‌وبرگشت HTTP؛ همچنین اعتبار ساختار REALITY. **نه نصب VPS، نه صدور ACME، نه CDN ایرانی، نه خط کاربر.**
- بررسی زندهٔ فقط‌خواندنی: صفحه ۲۰۰، API خصوصی ۴۰۱، join نامعتبر ۴۰۴، اسکریپت سالم؛ در هر دو D1 تعداد نودها صفر.
- اشتراک قبلی nova: ۶۶ رشتهٔ URI و ۵۰ دامنهٔ موجود حفظ شدند. این شمارش به معنی تست اتصال فعلی همهٔ لینک‌ها نیست.
