# دسترسی DNS تأیید شد؛ گام بعد CDN ایرانی — ۲۰۲۶-۱۰-۱۰

## نتیجهٔ واقعی توکن جدید
Cloudflare /user/tokens/verify با HTTP 200 وضعیت active داد. دسترسی خواندن zone و DNS برای هر دو دامنهٔ داده‌شدهٔ کاربر برقرار است؛ API مجوز DNS edit هم گزارش می‌کند. توکن از محدودهٔ درخواستی گسترده‌تر است (هر دو zone و مجوزهای اضافه)، بنابراین نباید آن را «فقط محدود به یک دامنه» معرفی کرد. از دسترسی‌های اضافی استفاده نشد.

- nnguts.dpdns.org: وضعیت active؛ ۱۴ رکورد موجود؛ یک صفحهٔ کامل نتایج دریافت و پشتیبان خصوصی ذخیره شد.
- drsarli.ir: وضعیت active؛ ۳ رکورد موجود؛ پشتیبان خصوصی ذخیره شد.
- spider-test.nnguts.dpdns.org در فهرست معتبر API وجود ندارد؛ هنوز هیچ رکوردی برای آن ساخته نشده است.
- هیچ DNS، NS، zone setting، Worker، حساب، دامنه یا پلنی تغییر نکرد.

توکن جدید در /home/user/cfpanel/cloudflare-domain-dns.token با دسترسی ۶۰۰ و جدا از اعتبارنامهٔ Workerهای Omni/Nova ذخیره شد. هش فایل .env پیش و پس از این عملیات یکسان بود. توکن و پشتیبان کامل DNS در Git یا Drive عمومی منتشر نمی‌شوند.

## دامنه داریم؛ دیگر توکن CF یا نام دامنه نخواهید
دادهٔ لازم این بخش دریافت و دسترسی تأیید شد. DNS ریشه و همهٔ رکوردهای موجود حفظ شوند. نام پیشنهادی جداگانه همان spider-test.nnguts.dpdns.org است، نه تغییر ریشهٔ دامنه یا drsarli.ir.

## محدودیت قیمت مهمی که از منبع رسمی پیدا شد
مستند رسمی فارسی Arvancloud می‌گوید CNAME Setup فقط در پلن‌های «رشد و بالاتر» است. در API نمونهٔ partial، plan_level=2 همان رشد است؛ 1=پایه، 3=حرفه‌ای. **نمونهٔ API docs را با plan_level=2 کپی و اجرا نکنید**؛ کاربر فقط آزمون رایگان را اجازه داده است.
صفحهٔ pricing/cdn در ابزار تنها صفحهٔ انتقال/بارگذاری برگرداند؛ مبلغ فعلی یا رایگان بودن گزینهٔ حساب کاربر هنوز تأیید نشده است.
مستند افزودن زیردامنه انتخاب NS Delegation یا CNAME Setup را نشان می‌دهد. مسیر کم‌تداخل قابل بررسی: واگذاری فقط زیردامنهٔ آزمایشی با NS روی پلن پایه، بدون تعویض NS دامنهٔ مادر. پذیرش این زیردامنه و هزینهٔ صفر باید در حساب واقعی بررسی شود؛ هنوز اجرا یا تضمین نشده است. NSهای نمونهٔ مستندات جای پاسخ واقعی حساب نیستند.

## قدم انسانی بعدی — ساده و بدون خرید
ورود به https://accounts.arvancloud.ir/login (اگر حساب ندارد ثبت‌نام از لینک رسمی https://accounts.arvancloud.ir/register?lang=fa)، بازکردن بخش «شبکه توزیع محتوا / CDN» و ارسال عکس صفحه. فعلاً هیچ پلن پولی، شارژ حساب، CNAME Setup، ورود دامنهٔ اصلی یا تغییر Nameserver انجام نشود.
هدف این توقف کوتاه، دیدن امکان و قیمت واقعی در پنل است؛ دادن توکن Cloudflare به معنی داشتن دسترسی Arvancloud نیست. Connector به نام arvancloud یک بار unsupported برگشت و نباید دوباره امتحان شود؛ API رسمی در صورت دریافت دسترسی مجازِ خود کاربر مسیر جداگانه‌ای است.

## برای مرحلهٔ بعدِ API آروان
راهنمای فارسی فعلی: تنظیمات → IAM → فهرست ماشین یوزرها → ساخت ماشین یوزر. نام ۵ تا ۱۰۰ کاراکتر، حروف کوچک/عدد/خط تیره. کلید از نوع apikey UUID است و فقط یک‌بار نمایش داده می‌شود. قوانین دسترسی باید مناسب CDN تعریف شوند؛ ماشین یوزر صرفاً ساخته‌شده را بدون بررسی مجوزها کامل فرض نکنید. رمز ورود و OTP کاربر را در گفتگو درخواست نکنید.

## وضعیت واقعی برنامه
Railway دسترسی آزمایشی داشت، ولی محدودیت AUP میزبانی پروکسی حل نشده است. خود SpiderPanel هنوز مستقر نشده و CDN ایرانی به origin وصل نشده است. تست مستقیم قبلی Railway روی خط کاربر ناموفق و deployment آن حذف شده؛ دوباره همان echo را راه نیندازید. هیچ کانفیگ فعال/نت ملی یا موفقیت کل زنجیره ادعا نشود.
