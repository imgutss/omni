## Worker changes (omni.v89.js)
- New shared DoH core in the DNS diag branch:
  - `omniDnsIsBogon(ip)` — RFC1918/loopback/link-local/benchmark/multicast detection.
  - `omniDnsResolveUrl(dohUrl, qname, qtype)` — 7s `AbortSignal.timeout`, strict-positive ms
    (`ms > 0 ? ms : 1`), honest verdicts: `ok | nxdomain | empty | http-error | no-answer`.
  - `omniDnsClassify(res, refIps)` — bogon answer ⇒ `poisoned`; overlap with reference ⇒ `ok`;
    otherwise `divergent`; when no reference exists, downgrades to un-compared `ok` (never fake poisoning).
  - `omniDnsReference(qname, qtype)` — Cloudflare DoH then Google DoH fallback.
- New `POST /api/diag/dns-batch` (session auth ⇒ anonymous 401):
  body `{qname, qtype, servers:[{id,url}]}`; qname regex `^[a-z0-9.-]{2,253}$` ⇒ 422;
  only `https://` URLs survive; hard cap 32 servers; concurrency 6;
  returns `{ok, qname, qtype, colo, ref_ips, at, results:[{id,url,ok,verdict,compared,ips,ms,http,error,at}]}`.
- Legacy `GET /api/diag/dns` keeps every old field and gains `verdict, ref_ips, compared, http, error, colo, via`.
- No D1 migration; no new bindings; rev146/147/148 code paths retained byte-for-byte around the splice.

## Bugs caught before deploy (do not reintroduce)
1. Template-literal escape collapse: replacement blocks inside backticks turned `\/`→`/`, `\d`→`d`,
   `\.`→`.`, producing a silently malformed URL-filter regex and a wrong `.$/` strip (would have removed
   the last char of every DNS answer). Fixed with `String.raw` + single backslashes; gate now asserts
   the exact regex literals.
2. Search matched every card because `textContent` includes the shared inspector label «Cloudflare/Google»;
   fixed with card-level `data-dns-haystack` scoped to identity fields.
3. change-events (hide-dead/qtype) needed an explicit `rerenderView("dns")` via `window.__omniE`.
