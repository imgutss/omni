# REV151 — 2026-10-28 — ارائهٔ صادقانهٔ محدودیت جغرافیایی رزولوورهای ایرانی

## مشکلی که در اسکرین‌شان دیده شد
پس از rev150 ستون ورکر برای ۱۴ رزولوور جهانی درست کار می‌کرد، اما هر ۵ رزولوور ایرانی
(شکن، الکترو، رادار گیم، بگذر، ۴۰۳) همچنان باج قرمز «خطای HTTP · 521/526/530» می‌گرفتند و
بخش شبیه «خراب» دیده می‌شد. ریشه یک محدودیت ذاتی شبکه است، نه باگ کد:
- ورکر روی لبهٔ جهانی کلادفلر خارج ایران اجرا می‌شود.
- رزولوورهای ایرانی فقط به کلاینت‌های داخل ایران سرویس می‌دهند (بعضی مثل رادار/۴۰۳ اصلاً روی
  رنج داخلی `10.202.10.x` اند) و originها آی‌پی دیتاسنتر کلادفلر را می‌بندند.
- بنابراین ستون «ورکر» برای این کارت‌ها اصلاً معنا ندارد و نمایش خطای قرمزِ ترسناک، گمراه‌کننده بود.
- ضمناً با VPN روشن، تست «خط من» هم برای سرویس‌های داخلی شکست می‌خورد (ترافیک از خارج رد می‌شود).

## طراحی rev151 (تغییر فقط در پنل؛ موتور DoH ورکر بدون تغییر ماند)
1. **`dnsGeoBlocked(id)`** — وقتی رزولوور کاتالوگ `region:"ir"` دارد و شکست حمل‌ونقلی است
   (`http-error` یا `no-answer`)، آن را «محدودیت جغرافیایی» می‌داند. verdictهای محتوایی
   (سالم/متفاوت/آلوده/NXDOMAIN/بدون رکورد) هرگز بلعیده نمی‌شوند — پاسخ واقعی DNS یعنی مسیر هست.
2. **باج کهربایی «☁ فقط داخل ایران»** روی کارت به‌جای باج قرمز خطا؛ tooltip توضیح می‌دهد و
   **کد خام HTTP (مثل 530) در inspector حفظ می‌شود** — صداقت کامل، فقط ارائهٔ معنادار.
3. **آمار تفکیکی سه‌گانهٔ شکست**: سطل جدا «فقط داخل ایران (غیرقابل سنجش از ورکر): N» کنار
   خطای HTTP واقعی سرویس‌های جهانی (مثل dns0.eu = 530) و NXDOMAIN/empty/no-answer.
4. **فیلتر «فقط زنده‌ها»** کارت‌های geo ایرانی را مخفی نمی‌کند (آن‌ها مرده نیستند، از ورکر
   غیرقابل‌سنجش‌اند)؛ فقط شکست‌های واقعی و آلوده پنهان می‌شوند.
5. **یادداشت ثابت روی هر کارت ایرانی** + به‌روزرسانی پاراگراف راهنما: تست واقعی با «خط من» و
   VPN خاموش؛ توضیح چرایی شکست با VPN روشن.
6. اصلاح کاتالوگ: IP رسمی شکن `178.22.122.100` (به‌جای `.122` اشتباهی، مطابق مستندات رسمی)؛
   یادداشت صادقانهٔ ۴۰۳: «گزارش‌هایی از توقف سرویس از اسفند ۱۴۰۳».

## نامتغیرهای صداقت (هر سه در E2E تست شدند)
- API ورکر دست‌نخورده و خام می‌ماند: همان verdictهای http-error/no-answer با کد واقعی برمی‌گردند؛
  لایه‌بندی geo کاملاً سمت پنل است و هیچ whitewash سرور-سمت وجود ندارد.
- آلودگی واقعی (پاسخ DNS با IP بوگان) حتی روی کارت ایرانی، باج قرمز «آلوده» می‌گیرد.
- هیچ ms صفر یا ساختایی نیست؛ شکست حمل‌ونقلی ms=null.
