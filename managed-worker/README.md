# Worker مدیریت‌شدهٔ پنل‌ها — build مستقل

این زیردرخت یک خط ساخت جداگانه برای Worker ربات مدیریت پنل‌ها است؛ با نسخهٔ کلاسیک
و منبع canonical موجود در `../production/` یکی نیست و آن پوشه را جایگزین نمی‌کند.

## وضعیت نسخه

- خط مبنا: `live/worker.js`، نسخهٔ مستقرشدهٔ main یعنی v53.4/rev77.
- خروجی ثبت‌شده: v53.5/rev78، شامل کشف Vercel با اعتبارنامه‌های خود کاربر و ارتقای
  درجا از دکمهٔ Telegram روی همان Worker انتخاب‌شده.
- انتشار روی Cloudflare انجام نشده است؛ باندل اینجا صرفاً artifact محلی برای بازبینی
  و انتشار مجاز بعدی است.

## ساخت و آزمون

```sh
node build.cjs
node --check build/worker.js
node test/smoke.mjs
```

`build/` تولیدی و قابل‌بازسازی است؛ artifact ثبت‌شدهٔ این انتشار در
`release/v53.5/` نگهداری می‌شود. آزمون smoke از توکن‌های ساختگی استفاده می‌کند.

## امنیت و انتشار

توکن Cloudflare را در فایل یا مخزن قرار ندهید. انتشار مستقیم به حساب مجاز به
`CF_API_TOKEN` تازه از محیط نیاز دارد؛ پس از build، اجرای `deploy.py` فقط با
مجوز صریح و تازه انجام شود. به‌روزرسانی پنل فرزند از خود ربات با اعتبارنامهٔ
Cloudflare همان مالک انجام می‌شود؛ این build به‌تنهایی هیچ Worker زنده‌ای را تغییر
نمی‌دهد.
