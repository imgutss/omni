# Worker مدیریت‌شدهٔ پنل‌ها — build مستقل

این زیردرخت یک خط ساخت جداگانه برای Worker ربات مدیریت پنل‌ها است؛ با نسخهٔ کلاسیک
و منبع canonical موجود در `../production/` یکی نیست و آن پوشه را جایگزین نمی‌کند.

## وضعیت نسخه

- خط مبنا: `live/worker.js` — **v53.7/rev82**، همان باندلی که هم‌اکنون روی Worker
  اصلی `omni` و پنل فرزند `omni-cloud-5649` مستقر است (بازیابی ۲۰۲۶-۱۰-۲۴؛
  جزئیات در `RELEASE_SYNC.fa.md`).
- جدیدترین ریلیز ثبت‌شده: `release/v53.7/` (rev82؛ Vercel کاملاً مستقل از بخش ۵).
  تاریخچه: v53.5/rev78 ارتقای درجا و جریان Vercel فورک‌شده، v53.6/rev79 استقلال
  بخش Vercel، v53.7/rev82 ادامهٔ همان خط که ابتدا فقط روی فرزند مستقر شده بود.
- انتشار از طریق `deploy.py` + بازنویسی کلید `releases/current` انجام می‌شود و هر
  build تازه باید در همان لحظه در همین مخزن commit شود تا تک‌نسخه نماند.

## ساخت و آزمون

```sh
node build.cjs
node --check build/worker.js
node test/smoke.mjs
```

`build/` تولیدی و قابل‌بازسازی است؛ artifact ثبت‌شدهٔ نسخهٔ جاری در
`release/v53.7/` نگهداری می‌شود. آزمون smoke از توکن‌های ساختگی استفاده می‌کند.

## امنیت و انتشار

توکن Cloudflare را در فایل یا مخزن قرار ندهید. انتشار مستقیم به حساب مجاز به
`CF_API_TOKEN` تازه از محیط نیاز دارد؛ پس از build، اجرای `deploy.py` فقط با
مجوز صریح و تازه انجام شود. به‌روزرسانی پنل فرزند از خود ربات با اعتبارنامهٔ
Cloudflare همان مالک انجام می‌شود؛ این build به‌تنهایی هیچ Worker زنده‌ای را تغییر
نمی‌دهد.
